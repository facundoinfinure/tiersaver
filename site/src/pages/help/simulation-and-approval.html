What a simulation shows

  • How many profiles were evaluated, how many would be suppressed, how many are protected and how many were skipped.
  • For the profiles that would be suppressed, the reason: never engaged, or engaged once and lapsed.
  • For protected profiles, which rule protected them. A profile can be covered by several rules.
  • A sample you can download and inspect.
  • The tier your list would fit afterwards, the estimated monthly saving at list price and the estimated fee.

A simulation changes nothing in Klaviyo.

Approving

When you approve a simulation, TierSaver suppresses exactly the profiles in that simulation and no others. Before it sends each batch to Klaviyo it leaves out any profile that can no longer be suppressed.

An approval is tied to one simulation:

  • It expires after {{sim.ttlHours}} hours. Lists change. If more time has passed, you get a fresh simulation to review.
  • It runs once. A simulation cannot be used for a second cleanup.
  • Changing your rules replaces it. If you edit a protection rule or a protected list, pending simulations are discarded.

The first cleanup is always manual

You start the first cleanup yourself, after reviewing its simulation. Scheduled cleanups only start after that.

Scheduled cleanups

Before each scheduled cleanup TierSaver runs a new simulation and emails you a summary. There are two modes:

  • Approval required (default). The cleanup waits for you to approve the simulation.
  • Automatic. An explicit opt-in. The cleanup runs on the scheduled day using the new simulation, and you still receive the summary.

See billing date scheduling for when cleanups run.

While a cleanup runs

Profiles are suppressed in batches. The app shows the state of the run: queued, running, completed, or completed with errors. If a run is interrupted, it resumes where it stopped without suppressing anyone twice or skipping a batch. If a batch keeps failing, the run stops and the remaining profiles are left untouched.
