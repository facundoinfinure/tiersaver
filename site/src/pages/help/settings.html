Who counts as inactive

By default TierSaver uses the criteria Klaviyo publishes for suppressing unengaged profiles: a profile created at least {{criteria.ageDays}} days ago that was sent {{criteria.emails}} or more emails in about {{criteria.weeks}} weeks and never opened, clicked, visited your site or purchased. Profiles with SMS consent, in a protected list or segment, or restored in the last {{criteria.undoLockDays}} days are always kept active.

Ticking the wider-windows box replaces "never" with time windows. This is TierSaver's own, stricter setting and goes beyond the criteria Klaviyo publishes. It shows these fields:

  • Purchased, clicked, opened, was on your site in the last (days). One field each. A profile with that activity inside the window is kept active. Leave a field empty for "ever". The shortest windows allowed are {{criteria.widerPurchaseDays}} days for purchases and {{criteria.widerEngagementDays}} days for the others.
  • Created or subscribed in the last (days). Newer profiles are kept active. Between {{criteria.widerAgeDays}} and {{criteria.maxAgeDays}} days.
  • Emails a profile must have received. Between {{criteria.emails}} and {{criteria.maxEmails}}. Nobody is inactive if you never wrote to them.
  • Ignore opens that Klaviyo flags as automatic (Apple Mail Privacy Protection). Off by default: every open keeps a profile active.

Automatic cleanups are not available with wider windows. See cleanup criteria for the reasoning.

Protected lists and segments

Profiles in a protected list or segment are never suppressed, whatever their activity. Tick the lists and segments you want to protect.

  • You can protect up to {{app.maxProtectedGroups}} lists and segments.
  • The page shows the first {{app.groupsListed}} lists and the first {{app.groupsListed}} segments of your Klaviyo account.
  • If a protected list or segment cannot be read during an audit, every profile is kept active.
  • A protected list or segment that Klaviyo no longer returns stays in your settings, marked as not found, and stays protected until you untick it.
  • Klaviyo has to be connected to choose lists and segments.

Monthly schedule

Off by default. See the monthly schedule and your Klaviyo plan for how the day is chosen.

  • Run the audit every month. Turns the schedule on or off. Turning it off takes effect at once and does not undo anything that already ran.
  • Day of the month your Klaviyo plan renews. A day from 1 to 31. Leave it empty to use the day Klaviyo reported in your last audit, when one is available.
  • Days before the renewal to run. Between {{schedule.minLeadDays}} and {{app.maxLeadDays}}. The default is {{schedule.leadDays}}.
  • Run the scheduled cleanup automatically, without waiting for my approval. Off by default. With it off, each scheduled audit waits for your approval for {{sim.ttlHours}} hours.

Automatic mode

Automatic mode lets the scheduled cleanup start without a separate approval each month. The app only accepts it when all of these hold:

  • the monthly schedule is on;
  • you use the default criteria, not wider windows;
  • you have already approved and run at least one cleanup yourself. Until then, scheduled simulations keep waiting for your approval.

Each automatic cleanup is charged like any other, under the rules in how pricing works, and is listed under History. The app does not send email about it. To stop it, untick the box or turn the schedule off.

When you change a setting

Changes apply when you confirm them with the button at the bottom of the page. If you change the criteria or the protected lists and segments, simulations that have not run yet are discarded: run the audit again before the next cleanup. Changing only the schedule does not discard them. If a value is outside its limits, the page says which one and nothing is changed.
