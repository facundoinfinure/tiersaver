Cleanup criteria: who is a candidate and who is always kept

By default a profile is a cleanup candidate only when it has no recorded engagement of any kind. When in doubt, the profile stays active.

Last updatedNovember 26, 2026

The default criteria

A profile is a candidate only if all of these are true:

  • It was created at least 365 days ago.
  • It has received at least 5 emails in roughly the last 72 weeks.
  • It has never opened an email.
  • It has never clicked an email.
  • It has never visited your site or started a checkout.
  • It has never purchased, checked against both your Shopify orders and Klaviyo.

These are the criteria Klaviyo publishes for suppressing unengaged profiles: created at least 365 days ago, 5 or more emails received over roughly the last 72 weeks, never opened or clicked, and no recorded site visits, product views, started checkouts or purchases. TierSaver adds its own checks on top: your Shopify orders, SMS consent and the lists you protect.

Who is always kept

  • Matched buyers. Any profile with a purchase in your Shopify orders or in Klaviyo. Orders are matched by email address, so a purchase made under a different address cannot be matched to the profile.
  • SMS subscribers. Any profile with SMS consent.
  • Protected lists and segments. Any list or segment you mark as protected, for example VIPs or wholesale accounts. You can protect up to 20. If a protected list or segment cannot be read during an audit, every profile is kept active.
  • Profiles with incomplete data. If TierSaver cannot see a profile's creation date, or cannot see far enough back in your order or engagement history to be sure, the profile stays.
  • Profiles restored by an undo. They are left out of cleanups for 365 days. See undo.

Profiles that are already suppressed, and profiles with no email address, are skipped entirely.

Buyers are checked twice

Klaviyo only knows about the purchases it has recorded. Your Shopify order history is an independent check. To match orders to Klaviyo profiles, TierSaver compares one-way hashes of email addresses, so it does not need to store your customers' email addresses. See data and privacy.

About opens

Klaviyo flags opens that may have been triggered by Apple's Mail Privacy Protection instead of a person. By default TierSaver counts those opens as engagement, which is the cautious choice: a flagged open keeps the profile. The wider mode has an option to ignore them.

The wider mode

You can opt in to a wider mode that uses time windows instead of "never". It is TierSaver's own, stricter setting: it goes beyond the criteria Klaviyo publishes, because it can also select people who engaged with you in the past, and the app says so when you turn it on. The windows cannot be set shorter than these floors:

SignalShortest window allowed
No opens, clicks or site activity182 days
No purchases365 days
Profile age180 days

SMS subscribers, protected lists and profiles with incomplete data are kept in the wider mode too. Automatic monthly cleanups are only available with the default criteria, never with the wider mode. Changing the criteria discards any simulation that has not run yet: run the audit again to get a new one to review. The fields are described in Settings.

Why the default criteria are narrow

Klaviyo's help center points out that a suppressed profile stays suppressed even if that person later starts a checkout or buys, and that suppressing too early can cost revenue. Suppression is meant for profiles that are truly inactive, so that is all the default mode selects.
