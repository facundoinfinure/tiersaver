Undo: correcting a run

Every run can be undone. Undo exists to correct a mistake: it restores exactly the profiles that run suppressed, and nothing else.

Last updated2026-11-25

The run log

Each cleanup is recorded: when it ran, whether you started it or the schedule did, who approved it, the criteria in effect, how many profiles were suppressed and how it ended. For each profile the log keeps the Klaviyo profile ID and the reason it was selected. That record is what makes undo exact.

What undo does

  • It removes the suppression from the profiles of one run.
  • It does not touch profiles that were suppressed by you, by Klaviyo or by another run.
  • It does not change consent. A profile that had unsubscribed before stays unsubscribed.

After an undo, the set of profiles suppressed by TierSaver is what it was before that run.

What happens to restored profiles

  • They count as active profiles again. Klaviyo's displayed count may take up to 72 hours to refresh after a large change.
  • TierSaver leaves them alone for 365 days. A restored profile is not eligible for any cleanup during that time. If you undo a run, you are telling TierSaver those profiles should stay.
  • Klaviyo has its own waiting period. Its help center says that once a profile is suppressed and then unsuppressed, it cannot be manually suppressed again until 90 days after the previous suppression. The rule is not active during the first 30 days after a new Klaviyo account is created.

What undo is not for

Undo is not a way to suppress profiles for a while and bring them back later. Suppression is a decision to stop emailing someone. If you expect to email a group again, protect it instead: mark the list or segment as protected in the cleanup criteria and it will never be selected.

If an undo is requested for a run that is more than one plan renewal old, the app asks you to confirm.
